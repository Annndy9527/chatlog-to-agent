# 存档与交接模板

本文件是空模板。填写后的真人状态属于隐私数据，不得放进公开仓库。

## 让助手生成完整状态

```text
存档。请基于当前会话生成一份完整的 Relationship State，供我人工核对并自行保存。

请分开列出：
1. 已确认事实及其日期或来源；
2. 双方已发生的主动行为；
3. 明确边界与拒绝；
4. 共同话题与待续话题；
5. 关键事件和已发生的邀约；
6. 当前推测、反例和未知事项；
7. 需要在下次对话继续关注的事。

不要把我的待发送草稿记为已发生，不要把旧推测升级为事实。若无法从上下文确认，保留“未知”。
```

人工核对后，可保存为以下结构：

```markdown
# Relationship State
- 版本：v001
- 对象代号：对象 A
- 覆盖时间：[起止日期]

## 已确认事实
- [日期、事实、证据]

## 已发生的互动
- 对方主动：[仅事实]
- 我主动：[仅事实]

## 明确边界
- [对方明确表达的内容]

## 关键事件与邀约
- [日期、发生了什么、结果]

## 待续话题
- [话题与来源]

## 推测和未知
- [推测、依据、其他可能]
- [尚不知道什么]

## 当前待办
- [下一步需要观察或自己决定的事]
```

## 换会话时

```text
交接。请输出最新的完整 Relationship State、最近关键事件、当前未完成事项和建议带入的新会话原始聊天范围。不要只输出增量；不要把推测当事实。
```

在新会话中提供人工核对过的状态，以及必要的少量近期聊天；同时注明“旧状态可能有错，新出现的明确事实可以修正它”。
