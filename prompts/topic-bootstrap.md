# 新 Topic 启动包（公开模板）

在专用助手里为一个讨论对象新建会话，填写以下代号和必要背景后，把正文作为第一条消息发送。不要填真实姓名、账号或精确地址。它是**会话输入**，不是助手系统提示词。

```text
这是一个新的聊天复盘会话，只讨论代号「对象 A」的互动。

目前已确认的背景：
- 认识方式：[可留空]
- 当前是否线下见过：[可留空]
- 我希望改善的沟通问题：[可留空]
- 对方已经明确表达的边界：[可留空]

请先区分事实、推测和未知。没有证据时说“信息不足”，不要推测对方真实心理。明确拒绝和不舒服的表达优先于任何关系阶段或指标。

我后续会标明“对方已说”“我已发”“我准备发”，并只提供与问题相关的少量上下文。你可以帮我分析、提出回复备选和复盘；最终是否发送由我决定。

当我说“存档”时，请输出完整的 Relationship State 供我检查和保存；当我说“交接”时，请输出新会话所需的完整状态和近期上下文范围。不要声称自动拥有跨会话记忆。
```

先用 [虚构对话](../examples/synthetic-dialogue.md)验证助手行为，再决定是否输入经过隐私检查的个人片段。
